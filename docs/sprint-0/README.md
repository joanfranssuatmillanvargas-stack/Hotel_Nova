## Sprints

HotelNova sigue siendo el mismo producto. El segundo corte fue el **Release 1** (Sprints 0 a 3, 5 roles,
52 historias, 158 puntos, terminado). El tercer corte es el **Release 2** (10 roles):

| Sprint | Fechas | Ítems |
|--------|--------|-------|
| R2-Sprint 0 · Preparación | 28/10 – 03/11/2026 | D01 a D06 |
| R2-Sprint 1 | 04/11 – 10/11/2026 | PBI-01, PBI-02, PBI-03 (13 pts) |
| R2-Sprint 2 | 11/11 – 17/11/2026 | PBI-04, PBI-05, PBI-06 (13 pts) |
| R2-Sprint 3 | 18/11 – 24/11/2026 | PBI-07, PBI-08 (8 pts) + PBI-09 extendido |

El avance se muestra en la hoja **Burndown** del Excel: un burndown por sprint del Release 2 y un
**Burn Up de todo el proyecto**, que parte de los 158 puntos del Release 1 y sube hacia 192.

El Sprint 0 no existe en Scrum puro: el taller hace la preparación dentro del Sprint 1. Aquí se
entrega por separado porque lo pide el docente, y se trata como la fase de preparación.
